## PR 模板

```markdown
## 添加 MemoryAgent

**项目名称:** MemoryAgent
**项目地址:** https://github.com/jaychouya/MemoryAgent
**简介:** 具备认知记忆架构的 AI Agent，让 AI 记住你的偏好

### 为什么值得加入？

1. **独特的记忆系统** - 四类型记忆（用户画像/行为反馈/项目动态/外部引用）
2. **本地优先** - 所有数据存储在本地，隐私可控
3. **Obsidian 兼容** - 记忆文件可直接在 Obsidian 中编辑
4. **15+ 模型支持** - OpenAI、DeepSeek、通义千问、MiMo 等
5. **Claude Code 架构** - 参考 Claude Code 源码设计

### 技术栈

- Python 3.9 + FastAPI (后端)
- Next.js 14 + TypeScript (前端)
- Markdown + SQLite (存储)
- networkx (技能图谱)

### 测试覆盖

- 400+ 测试用例
- 完整的单元测试和集成测试

### 文档

- 完整的 README
- API 文档
- 架构设计文档
```

## 操作步骤

1. Fork 目标仓库
2. 在 README.md 中找到合适的位置
3. 添加项目链接和描述
4. 提交 PR
5. 等待审核

## 注意事项

- 选择正确的分类位置
- 描述简洁明了
- 遵循仓库的格式规范
- 不要过度宣传
